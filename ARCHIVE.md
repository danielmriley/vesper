# Vesper archive — ClearMain

This branch is a frozen snapshot of the original Vesper project: a
PyTorch-like C++17 deep-learning library with autograd, training loops,
HIP/CUDA kernels, and a TinyStories-oriented transformer stack.

It is kept so that work can continue on the library independently of the
inference-engine rewrite that starts from an empty tree.
